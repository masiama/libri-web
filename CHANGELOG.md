# Changelog

All notable changes to this project are listed here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-02

The new design.

### Added

- New look: design tokens, fonts, restyled buttons and a sticky app header with the logo and a scan button.
- Library as a grid of book covers, with loading placeholders, a compact pager (the page is kept in the URL) and a retry screen when the library fails to load.
- Search the library by title or author.
- Book detail page, behind a signed-in layout:
  - ISBN card with a copy button.
  - Scannable barcode card with Reading Rex.
  - Share button.
  - "Buy on {store}" link.
  - A 3D book you can drag to turn and tap to open. It is sized from its images and colors its spine and back from the front cover.
  - Loading, not-found and failed-to-load states.
- Scan page, replacing the scanner popup:
  - Dark screen with a reticle and laser.
  - Type an ISBN by hand.
  - "Looking up" and "Found" cards.
  - Not-in-catalogue and unreadable-code messages.
  - "This session" list and a count of scanned books.
  - Camera permission messages and a camera picker.
- Account menu (bottom sheet on phones, dropdown on larger screens) with a dark theme switch.
- Sign-in and sign-up pages with an email code step.
- Password strength meter on sign-up, with a peeking dino that reacts to focus, errors and success.
- Password reset by email code.
- Links out of sign-in and sign-up errors.
- Messages when copying the ISBN or share link fails.
- A 404 page.
- Tests for the theme, back and sign-in hooks, and the ISBN fix.

### Changed

- The barcode scanner moved from a popup on the book list to its own page.
- Regenerated the API client from the updated OpenAPI schema.
- Updated dependencies.

### Fixed

- Book titles now carry their language, and password strength is announced to screen readers.
- Even cover corners and a clear button in the search field.
- Matching sizes on book pages, and long titles now wrap.
- Header size and transparency, account menu icon, label and shadow, and the toast icon.

## [0.1.0] - 2026-09-27

First working version (MVP): API connection and barcode scanning.

### Added

- App set up with TanStack Router, with the oxc linter and formatter.
- Sign-in with Clerk.
- API client generated by Orval, with a paginated book list.
- Barcode scanner popup on the book list.

### Fixed

- Response bodies are read according to their content type instead of being assumed.
